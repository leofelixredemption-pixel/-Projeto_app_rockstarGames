# 🎮 Projeto Rockstar Games

Uma aplicação Web Mobile inspirada na Rockstar Games, desenvolvida com HTML, CSS e JavaScript.

O objetivo é apresentar alguns dos jogos mais conhecidos da desenvolvedora, reunindo títulos clássicos que marcaram gerações em uma experiência adaptada para dispositivos móveis.

## 📌 Sobre o projeto

O projeto foi desenvolvido com foco em responsividade e experiência mobile, permitindo que os usuários naveguem pela página inicial e escolham entre os jogos disponíveis.

O escopo contempla apenas alguns títulos da Rockstar Games, priorizando a organização e a qualidade do desenvolvimento.

## 🚀 Funcionalidades

- Página inicial para apresentação dos jogos.
- Seleção de jogos pelo usuário.
- Navegação entre os conteúdos disponíveis.
- Interface desenvolvida com foco em dispositivos móveis.
- Layout adaptado para diferentes resoluções.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Visualização Mobile

Para visualizar melhor a proposta do projeto, recomendo utilizar a extensão **Mobile Preview**, disponível no Visual Studio Code.

A extensão permite visualizar a aplicação em diferentes modelos de celulares e tablets.

**Dispositivo utilizado como referência durante o desenvolvimento:**
- iPhone 17 Pro Max.

## ⚙️ Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/leofelixredemption-pixel/-Projeto_app_rockstarGames.git
   ```

2. Abra a pasta do projeto no Visual Studio Code.

3. Instale a extensão Mobile Preview.

4. Abra o arquivo inicial `index.html` ou utilize o servidor local configurado para o projeto.

5. Selecione um dispositivo no Mobile Preview para visualizar a aplicação.
